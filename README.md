# PLAYDATA 캠퍼스 메타버스

실제 캠퍼스 설계도와 실내 사진을 바탕으로 만든 2D 맵 탐방 프로토타입입니다. 캐릭터를 움직여 강의실과 라운지를 둘러보고, 시설 안내와 참고 사진을 확인할 수 있습니다.

문서 기준일은 2026년 10월 5일입니다. 안내 데스크의 의자 2개, 줄어든 탁자 폭, 휴게 공간과 데스크 사이 외벽의 유리 출입문까지 반영한 상태를 설명합니다.

## 실행 방법

배포된 사이트는 [PLAYDATA 캠퍼스 맵](https://playdata-campus-metaverse.mlops-1-7302.chatgpt.site)에서 열 수 있습니다. 접근 권한이 있는 계정으로 접속해 주세요.

소스를 내려받았다면 압축을 푼 뒤 `dist/index.html`을 웹 브라우저로 열면 됩니다. 기본 실행에는 패키지 설치나 빌드가 필요하지 않습니다. 파일 선택부터 수정 후 확인까지의 절차는 [실행 가이드](RUN_GUIDE.md)에 정리했습니다.

## 현재 구현한 기능

| 기능 | 동작 |
| --- | --- |
| 캐릭터 이동 | WASD, 방향키 또는 모바일 방향 버튼으로 이동 |
| 자동 이동 | 빈 바닥을 클릭하면 벽과 가구를 피해서 이동 |
| 공간 선택 | 왼쪽 공간 목록에서 선택한 장소로 바로 이동 |
| 지도 조작 | 드래그, 확대와 축소, 전체 보기, 내 위치 따라가기 |
| 시설 안내 | 시설 클릭 또는 가까운 시설 옆에서 E를 눌러 설명과 참고 사진 확인 |
| 캐릭터 색상 | 옷 색상 변경 |
| 지도 저장 | 4896 × 2460 픽셀 PNG 다운로드 |

현재는 단일 사용자 탐방용입니다. 실시간 다중 접속, 채팅, 음성 통화, 화상 통화, 화면 공유, 계정 및 데이터 저장은 구현하지 않았습니다. TV와 노트북은 지도에 표현된 시설이며 실제 PC 연결이나 영상 전송 기능은 없습니다.

## 최신 맵 배치

### 강의실

- 모든 강의실의 강의 전면과 학생 좌석 방향을 강의실 1과 2의 아래쪽 방향으로 통일했습니다.
- 강의실 1부터 4까지의 출입문은 중앙 복도 양 끝에 배치했습니다.
- 왼쪽 상단, 중단, 하단 강의실을 강의실 3과 4와 비슷한 크기로 넓히고 학생 책상을 4열 3줄로 배치했습니다.

### 라운지 1

- 브라운 벽을 강의실 1 옆면에 붙이고, 사진의 작은 흰 탁자와 원형 스툴을 벽을 따라 배치했습니다.
- 위쪽으로 옮긴 2칸 소파가 아래 소파와 마주보도록 배치했습니다.
- 안내 데스크의 탁자 폭을 줄이고 직원용 의자를 2개로 늘렸습니다. 의자 외에 데스크 뒤쪽 탁자나 수납 가구는 두지 않았습니다.
- 휴게 공간과 안내 데스크 사이 아래쪽 외벽에 유리 슬라이딩 출입문을 배치했습니다. 기존 실내 유리 칸막이는 제거했고, 열린 문을 지나 바깥 출입구와 라운지를 오갈 수 있습니다.
- 위쪽에는 노트북 한 대가 놓인 긴 탁자와 세 회의 탁자별 PC 연결용 TV를 배치했습니다.
- 두 기둥 주변에는 책장을 배치했습니다.
- 상단 휴게 설비는 정수기, 커피머신, 세 분리수거함, 대형 사무용 프린터 순서로 배치했습니다. 프린터는 분리수거함과 창고 사이에 있습니다.

### 라운지 2

- 중앙 소파를 제거했습니다.
- 상단 정수기를 맨 오른쪽 끝에 두고 분리수거함을 함께 배치했습니다.
- 위쪽 긴 탁자의 PC 연결용 TV를 탁자 중앙선에 맞춰 위쪽에 배치했습니다.
- 오른쪽 벽면에는 바 테이블이 있습니다.
- 아래쪽 회의공간 1과 2의 크기, 벽, 출입문, 탁자, 의자, TV 배치는 기존 구조를 유지했습니다.

### 상담실과 기타 공간

상담실 A는 노란색, 상담실 B는 주황색 벽을 반영했습니다. 각 상담실에는 상담 테이블, 의자, 모니터가 있습니다. 설계도의 복도, 직원실, 창고, 회의실, 계단도 포함했습니다. 사진이 없는 강의실, 직원실, 회의실의 가구는 기본 구성으로 배치했습니다.

## 소스 구성

이 프로젝트에서는 `dist` 폴더에 실제 HTML, CSS, JavaScript 원본이 들어 있습니다.

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 화면 구조와 버튼, 안내 창 |
| `dist/style.css` | 화면 디자인과 모바일 배치 |
| `dist/map-data.js` | 방, 벽, 출입구, 가구의 위치와 시설 설명 |
| `dist/campus.js` | Canvas 지도 표시, 캐릭터 조작, 화면 조작과 안내 |
| `dist/navigation.js` | 벽과 가구를 피하는 자동 이동 |
| `dist/assets/` | 원본 설계도, 참고 사진, 지도 PNG |
| `README.md` | 프로젝트 설명과 최신 구현 상태 |
| `RUN_GUIDE.md` | 실행 방법, 조작법, 수정 후 확인 방법 |
| `README.txt` | 간단한 실행 안내를 담은 텍스트 문서 |

## 확인한 사항

18개 실내 공간 사이의 이동 경로, 벽과 주요 가구의 충돌, 외부 출입구와 라운지 사이의 통과를 확인했습니다. 회의공간 1과 2의 기존 구조 유지, 안내 데스크 좌석 2개, TV 정렬, 강의실과 소파 배치도 확인했습니다. 데스크톱 및 모바일 화면과 시설 안내, 별도로 제공한 단일 HTML 파일의 스크립트와 이미지 포함 상태를 확인했습니다.
