# PLAYDATA 캠퍼스 메타버스

실제 캠퍼스 설계도와 실내 사진을 바탕으로 만든 2D 맵 탐방 프로토타입입니다. 캐릭터를 움직여 강의실과 라운지를 둘러보고, 시설 안내와 참고 사진을 확인할 수 있습니다.

문서 기준일은 2026년 10월 6일입니다. 캠퍼스 지도, Django 계정·닉네임과 웹소켓 실시간 접속 기능을 포함한 상태를 설명합니다.

## 실행 방법

배포된 사이트는 [PLAYDATA 캠퍼스 맵](https://playdata-campus-metaverse.mlops-1-7302.chatgpt.site)에서 열 수 있습니다. 접근 권한이 있는 계정으로 접속해 주세요.

회원가입·로그인을 이용하려면 아래 Django 실행 방법을 따릅니다. 지도만 미리 확인하려면 `dist/index.html`을 웹 브라우저로 열어도 됩니다. 파일 선택부터 수정 후 확인까지의 절차는 [실행 가이드](RUN_GUIDE.md)에 정리했습니다.

## 현재 구현한 기능

현재 저장소에는 로그인 후 지도 화면을 제공하는 Django 프로젝트가 포함되어 있습니다. 가상환경과 의존성을 준비한 뒤 `run-local.cmd`를 실행하면 `http://127.0.0.1:8002/`에서 로그인 화면을 열 수 있습니다. 처음 설치하는 방법은 [실행 가이드](RUN_GUIDE.md)의 Django 실행 항목을 참고해 주세요.

같은 와이파이·공유기의 조원은 실행 창에 표시되는 서버 PC의 내부 IP 주소로 접속합니다. 현재 이 PC의 주소는 `http://192.168.0.77:8002/`입니다. 처음 한 번 `allow-lan.cmd`를 관리자 권한으로 실행해 현재 LAN의 TCP 8002 접속 규칙을 준비합니다. 서버는 `0.0.0.0:8002`에서 실행되며 허용 호스트는 이 PC의 실제 사설 주소로 제한합니다. 자세한 절차와 IP 변경 시 갱신 방법은 실행 가이드에 정리했습니다.

Django에서 아이디·비밀번호·닉네임으로 회원가입할 수 있습니다. 가입하면 자동으로 로그인되어 지도로 이동하며, 로그인 전에는 로그인 화면으로 안내합니다. 계정, 닉네임과 로그인 세션은 로컬 SQLite 데이터베이스에 저장하고 비밀번호는 해시로 저장합니다. 기존 계정은 지도 상단의 이름을 눌러 닉네임을 설정하거나 변경할 수 있습니다.

| 기능 | 동작 |
| --- | --- |
| 회원가입·닉네임 | 아이디, 비밀번호 확인, 2~20자 닉네임 설정, 가입 후 지도 입장, 기존 계정도 닉네임 변경 가능 |
| 실시간 접속 | 같은 서버에 접속한 캐릭터의 이동·방향·옷 색상 공유, 다른 캐릭터 머리 위에 닉네임 표시, 접속 수 표시 |
| 입장·퇴장 | 새 접속자는 현재 접속자를 바로 표시, 로그아웃·탭 닫기는 캐릭터 제거, 일시적인 연결 끊김은 자동 재연결 |
| 로그인·로그아웃 | 계정으로 로그인, 새로고침 후 로그인 유지, 지도 상단 또는 외부 출입구의 확인 창에서 로그아웃 |
| 외부 출입구 | 나갈 때 “나가시겠습니까?” 표시, 예는 로그아웃 후 로그인 화면으로 이동, 아니오 또는 Esc는 출입문 안쪽으로 돌아와 지도 이용 계속 |
| 캐릭터 이동 | WASD, 방향키 또는 모바일 방향 버튼으로 이동 |
| 자동 이동 | 빈 바닥을 클릭하면 벽과 가구를 피해서 이동 |
| 공간 선택 | 왼쪽 공간 목록에서 선택한 장소로 바로 이동 |
| 지도 조작 | 처음에는 내 위치를 확대한 화면으로 시작, 드래그와 확대·축소, 전체 보기 및 내 위치 따라가기 전환 |
| 시설 안내 | 시설 클릭 또는 가까운 시설 옆에서 E를 눌러 설명과 참고 사진 확인 |
| 캐릭터 색상 | 옷 색상 변경 |
| 지도 저장 | 4896 × 2460 픽셀 PNG 다운로드 |

실시간 다중 접속은 로컬 Django 서버에서 동작합니다. 파일로 직접 여는 지도와 기존 배포 사이트는 지도 탐방용입니다. 채팅, 음성·화상 통화, 화면 공유와 이동 로그 저장은 구현하지 않았습니다. TV와 노트북은 지도에 표현된 시설이며 실제 PC 연결이나 영상 전송 기능은 없습니다.

현재 서버는 Django Channels와 Daphne로 HTTP·웹소켓을 함께 제공합니다. 이동 좌표는 소수점을 유지하며 최대 초당 10회 전송하고, 다른 캐릭터는 중간 위치를 보간해 표시합니다. 위치를 DB에 매번 저장하지 않으며 지도를 새로 열면 시작 지점에서 입장합니다. 로그인 세션과 허용된 출처를 확인하며, 외부 탭에서 로그아웃해도 최대 약 10초 안에 해당 연결을 종료합니다.

접속자 목록과 전달 채널은 한 서버 프로세스의 메모리에 있습니다. 여러 프로세스·서버로 운영할 때는 전달 채널과 접속자 상태를 함께 Redis 등 공유 저장소로 옮겨야 합니다. 현재 이동 판정은 클라이언트가 담당하고 서버는 좌표 범위와 메시지 형식을 검사합니다.

## 최신 맵 배치

### 강의실

- 모든 강의실의 강의 전면과 학생 좌석 방향을 강의실 1과 2의 아래쪽 방향으로 통일했습니다.
- 강의실 1부터 4까지의 출입문은 중앙 복도 양 끝에 배치했습니다.
- 왼쪽 상단, 중단, 하단 강의실을 강의실 3과 4와 비슷한 크기로 넓히고 학생 책상을 4열 3줄로 배치했습니다.

### 라운지 1

- 라운지 1의 화분을 모두 제거했습니다.
- 오른쪽 기둥과 책장을 오른쪽·아래로 조금 옮기고, 기둥 위에 세로로 붙인 긴 작업 탁자에는 콘센트 4곳과 오른쪽 네 좌석을 배치했습니다.
- 두 기둥 사이 통로가 비도록 중앙 위쪽에 나무 테두리의 이동식 칠판 게시판을 놓고 `playdata`를 적었습니다. 아래 받침에만 충돌을 적용하여 칠판 뒤쪽으로 걸어갈 수 있습니다.
- 브라운 벽을 강의실 1 옆면에 붙이고, 사진의 작은 흰 탁자와 원형 스툴을 벽을 따라 배치했습니다.
- 위쪽으로 옮긴 2칸 소파가 아래 소파와 마주보도록 배치했습니다.
- 안내 데스크의 탁자 폭을 줄이고 직원용 의자를 2개로 늘렸습니다. 의자 외에 데스크 뒤쪽 탁자나 수납 가구는 두지 않았습니다.
- 휴게 공간과 안내 데스크 사이 아래쪽 외벽에 유리 슬라이딩 출입문을 배치했습니다. 기존 실내 유리 칸막이는 제거했고, 열린 문을 지나 바깥 출입구와 라운지를 오갈 수 있습니다.
- 위쪽에는 노트북 한 대가 놓인 긴 탁자와 세 회의 탁자별 PC 연결용 TV를 배치했습니다.
- 두 기둥 주변에는 책장을 배치했습니다.
- 상단 휴게 설비는 정수기, 커피머신, 세 분리수거함, 대형 사무용 프린터 순서로 배치했습니다. 프린터는 분리수거함과 창고 사이에 있습니다.

### 라운지 2

- 중앙 소파를 제거했습니다.
- 상단 정수기를 맨 오른쪽 끝에 두고 분리수거함을 함께 배치했습니다.
- 위쪽 긴 탁자의 PC 연결용 TV를 탁자 중앙선에 맞춰 위쪽에 배치했습니다.
- 오른쪽 벽면에는 바 테이블이 있습니다.
- 아래쪽 회의공간 1과 2의 크기, 벽, 출입문, 탁자, 의자, TV 배치는 기존 구조를 유지했습니다.

### 상담실과 기타 공간

상담실 A는 노란색, 상담실 B는 주황색 벽을 반영했습니다. 각 상담실에는 상담 테이블, 의자, 모니터가 있습니다. 설계도의 복도, 직원실, 창고, 회의실, 계단도 포함했습니다. 사진이 없는 강의실, 직원실, 회의실의 가구는 기본 구성으로 배치했습니다.

## 소스 구성

이 프로젝트에서는 `dist` 폴더에 실제 HTML, CSS, JavaScript 원본이 들어 있습니다.

| 파일 | 역할 |
| --- | --- |
| `manage.py`, `config/` | Django 실행 명령과 프로젝트 설정 |
| `campus/` | 지도 페이지, 인증된 웹소켓 접속과 실시간 이동 전달 |
| `accounts/` | 회원가입·로그인·로그아웃, 닉네임 모델·설정 화면과 동작 테스트 |
| `db.sqlite3` | 로컬 계정·닉네임·세션 데이터 (Git 제외) |
| `requirements.txt` | Django, Channels와 Daphne 의존성 |
| `run-local.cmd` | Windows에서 Django 로컬 서버 실행 |
| `run-campus.py` | 같은 네트워크용 서버 실행과 접속 주소 표시 |
| `allow-lan.cmd`, `configure-lan.py` | 현재 LAN의 TCP 8002 접속만 허용하는 방화벽 설정 |
| `dist/index.html` | 화면 구조와 버튼, 안내 창 |
| `dist/style.css` | 화면 디자인과 모바일 배치 |
| `dist/map-data.js` | 방, 벽, 출입구, 가구의 위치와 시설 설명 |
| `dist/campus.js` | Canvas 지도 표시, 캐릭터 조작, 화면 조작과 안내 |
| `dist/presence.js` | 웹소켓 연결·재연결, 다른 캐릭터 상태와 이동 보간 |
| `tests/presence.test.cjs` | 전송 주기·좌표 정밀도·닉네임·재연결·로그아웃 검사 |
| `dist/navigation.js` | 벽과 가구를 피하는 자동 이동 |
| `dist/assets/` | 원본 설계도, 참고 사진, 지도 PNG |
| `README.md` | 프로젝트 설명과 최신 구현 상태 |
| `RUN_GUIDE.md` | 실행 방법, 조작법, 수정 후 확인 방법 |
| `README.txt` | 간단한 실행 안내를 담은 텍스트 문서 |

## 확인한 사항

18개 실내 공간 사이의 이동 경로, 벽과 주요 가구의 충돌, 외부 출입구와 라운지 사이의 통과를 확인했습니다. 회의공간 1과 2의 기존 구조 유지, 안내 데스크 좌석 2개, TV 정렬, 강의실과 소파 배치도 확인했습니다. 데스크톱 및 모바일 화면과 시설 안내, 별도로 제공한 단일 HTML 파일의 스크립트와 이미지 포함 상태를 확인했습니다.

회원가입·닉네임 저장과 수정, 로그인·로그아웃, 접근 제한·CSRF 보호, 두 계정의 입장·이동·퇴장과 세션 종료, 내부 IP 검출을 `manage.py test accounts campus config`로 검사할 수 있습니다. 별도 브라우저 두 로그인으로 닉네임 표시·이동 공유·퇴장도 확인했습니다. JavaScript 동작 검사는 Node.js가 있으면 `node tests/presence.test.cjs`로 실행합니다.
