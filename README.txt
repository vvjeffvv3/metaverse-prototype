PLAYDATA 캠퍼스 메타버스

실제 설계도와 사진을 반영한 2D 맵 탐방용 프로토타입입니다.

문서 기준일: 2026년 10월 6일
프로젝트 설명: README.md
상세 실행 가이드: RUN_GUIDE.md

실행
0. Django 로컬 실행: 프로젝트 폴더에서 run-local.cmd를 더블 클릭하고 http://127.0.0.1:8002/에 접속합니다.
   다른 PC의 첫 설치 방법은 RUN_GUIDE.md의 Django 실행 항목을 참고하세요.
   회원가입할 때 닉네임을 정하면 바로 지도로 이동합니다. 기존 계정은 아이디와 비밀번호로 로그인하고 지도 상단의 이름을 눌러 닉네임을 설정할 수 있습니다.
   지도 상단의 로그아웃 버튼으로 로그아웃할 수 있습니다.
   같은 와이파이·공유기의 조원은 서버 PC 실행 창에 표시되는 내부 IP 주소로 접속합니다. 현재 주소는 http://192.168.0.77:8002/입니다.
   최초 한 번 allow-lan.cmd를 관리자 권한으로 실행하여 현재 LAN의 TCP 8002 접속만 허용합니다. 네트워크가 바뀌면 다시 실행합니다.
1. 배포 사이트: https://playdata-campus-metaverse.mlops-1-7302.chatgpt.site
   접근 권한이 있는 계정으로 열어 주세요.
2. 소스 실행: PLAYDATA-campus-source.zip을 압축 해제한 뒤 dist/index.html을 웹 브라우저에서 열어 주세요.
   dist 폴더 전체를 함께 유지하면 별도 패키지 설치나 빌드 없이 실행됩니다.
3. 단일 파일 실행: 별도로 제공된 PLAYDATA-campus.html을 웹 브라우저로 엽니다.
   이 파일에는 코드와 사진, 지도 이미지가 포함되어 있습니다.

코드를 수정한 뒤에는 저장하고 로컬 페이지를 새로고침해 주세요.
로컬 서버 실행과 문제 해결 방법은 RUN_GUIDE.md에 정리했습니다.

조작
- WASD 또는 방향키: 캐릭터 이동
- 빈 바닥 클릭: 벽과 가구를 피해 자동 이동
- 맵 드래그: 지도 이동
- 마우스 휠 / + / -: 확대·축소
- 왼쪽 공간 목록: 해당 공간으로 바로 이동
- 시설 클릭 / 시설 옆 E: 안내 및 참고 사진
- 전체 보기 / 스페이스: 전체 맵
- 내 위치: 캐릭터 따라가기
- 맵 PNG 저장: 4896 × 2460 지도 이미지 저장
- 모바일에서는 화면 왼쪽 아래 방향 버튼을 이용할 수 있습니다.

반영한 배치
- 모든 강의실: 강의실 1·2와 같은 아래쪽 전면 방향으로 통일, 강의실 1–4의 문은 복도 양 끝에 유지
- 왼쪽 상·중·하 강의실: 각각 3·4번과 비슷한 크기로 확대, 학생 책상을 4열·3줄로 배치
- 복도 오른쪽 라운지 1: 강의실 1 옆면에 붙인 브라운 벽을 기준으로 사진의 소파·흰 탁자·원형 스툴을 회전 배치
- 안내 데스크: 탁자의 폭을 줄이고 직원용 의자를 2개 배치
- 유리 출입문: 휴게 공간과 안내 데스크 사이의 아래쪽 외벽에 배치, 바깥 출입구에서 라운지로 이동 가능
- 라운지 1의 2칸 소파: 위로 옮겨 아래 소파와 마주보도록 배치
- 라운지 1 위쪽: 정수기 옆 커피머신·세 분리수거함, 분리수거함과 창고 사이 대형 사무용 프린터, 노트북 한 대가 놓인 긴 탁자, 세 회의 탁자별 PC 연결용 TV 한 대, 두 기둥의 책장
- 복도 왼쪽 라운지 2: 중앙 소파 제거, 상단 오른쪽 끝의 정수기·분리수거, 긴 회의 테이블과 오른쪽 벽면 바 테이블, 아래쪽 두 회의공간
- 라운지 2의 위쪽 긴 탁자: PC 연결용 TV를 탁자 중앙선에 맞춰 위쪽에 배치
- 회의공간 1·2: 기존 크기와 벽·탁자·의자·TV 배치 유지
- 상담실 A: 노란색 벽 / 상담실 B: 주황색 벽
- 설계도의 강의실, 복도, 직원실, 창고, 회의실, 계단

사진이 없는 강의실·직원실·회의실의 가구는 기본 구성으로 배치했습니다.
설계도에 표시되지 않은 출입구의 위치는 이동 동선을 고려해 추정했습니다.
계정·닉네임·로그인 세션은 db.sqlite3에 저장하며, 비밀번호는 해시로 저장합니다.
Django 서버에서는 로그인한 사람끼리 실시간으로 이동·방향·옷 색상을 공유하고, 다른 캐릭터 머리 위에 닉네임이 표시됩니다. 현재 위치는 서버 한 프로세스의 메모리에서 공유하며 영구 저장하지 않습니다.
파일 미리보기와 기존 배포 사이트는 지도 탐방용입니다. 채팅·음성/화상 통화·화면 공유·이동 로그 저장은 구현하지 않았습니다.
TV와 노트북은 지도에 표현된 시설이며 실제 PC 연결이나 영상 전송 기능은 없습니다.

편집용 파일
- accounts/: 회원가입·로그인·로그아웃, 닉네임 저장·설정
- campus/: 지도 페이지와 인증된 실시간 웹소켓 연결
- run-campus.py: LAN 서버 실행과 현재 내부 IP 접속 주소 표시
- allow-lan.cmd / configure-lan.py: 같은 LAN의 TCP 8002 접속 허용
- dist/index.html: 화면 구조와 버튼, 안내 창
- dist/map-data.js: 방, 벽, 가구 위치와 공간 안내
- dist/campus.js: 지도 렌더링, 캐릭터, 화면 조작
- dist/navigation.js: 충돌을 피하는 자동 이동
- dist/presence.js: 웹소켓 연결과 다른 캐릭터의 실시간 이동
- dist/style.css: 화면 구성
- dist/assets: 참고 사진과 내보낸 지도 PNG

18개 실내 공간의 동선과 외부 유리 출입문 통과, 벽과 주요 가구의 충돌, 데스크톱·모바일 화면 및 공간 안내를 확인했습니다.
